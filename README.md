STM32 Digital Clock Project

This project is a digital clock that displays the day of the week, date, month, year, and time.

It uses the following components:

LCD 16×2 I²C: Displays the date and time.
DS3231 RTC: Keeps track of the date and time.
KY-040 Rotary Encoder: Allows user interaction and adjustment of settings when needed.

The project is developed using C and the STM32 HAL library to practice embedded programming, I²C communication, GPIO control, and peripheral integration.
